# Beam Designer

Beam Designer is a Python desktop app for checking simply supported and
cantilever beams. It calculates reactions, shear, moment, deflection, and
bending checks, and can save designs and export results to CSV or PDF.

Install Python 3.10 or later with Tkinter. No third-party packages are needed.
On systems where Tkinter is packaged separately, install the system's Tkinter
package (for example, `python3-tk` on Debian or Ubuntu).

From the project directory, start the app with:

```sh
python beam_designer.py
```
